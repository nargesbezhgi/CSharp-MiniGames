# MiniGames

A simple C# Windows Forms application that contains several mini games.

## Games

- Rock Paper Scissors
- Snakes and Ladders
- Word Guessing Game
- Quiz Game

## Features

- User login before accessing the games
- Simple and friendly interface
- Multiple mini games in one application
- Score tracking
- Timer-based challenges

## Project Structure

- `Form1` - Start Page
- `Form2` - Main Menu
- `Form3` - Rock Paper Scissors
- `Form4` - Quiz Game
- `Form5` - Word Guessing Game
- `Form6` - User Login
- `mar` - Snakes and Ladders
